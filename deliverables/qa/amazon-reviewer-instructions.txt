Fixavora 1.0.0 (version code 2) is a touch-first offline home-maintenance organiser. No Fixavora login or test credentials are required. Complete onboarding, create a property, then add a maintenance task; review assistant drafts before saving. Free tier: one active property and 15 active tasks. Premium is the one-time Amazon entitlement fixavora.premium.lifetime; use an Amazon review/test account for purchase and Settings > Restore purchases. Internet is required for Amazon receipt verification; home records remain local and usable offline. Production verification: fixavora-receipts.lanraybanks.workers.dev. App Tester purchase/receipt restoration and live sandbox verification passed on Fire HD 10 (2021). Production charging and Amazon-signed delivery have not been tested. Premium reports export PDF/CSV through the system file picker. Encrypted backups contain records/history, exclude external files/photos/attachment links, and require the chosen passphrase. Restore confirms before replacing records. Attachments use the Android picker. Speech input depends on an installed compatible recognizer; the tested Fire has none, so typing is the supported fallback. Three English TTS variants synthesized on the test device; other voices depend on installation. Choose language manually in Settings (22 UI locales including Arabic RTL). Reminders are periodic, respect quiet hours, and can be delayed by power settings. Settings > Delete all home data removes local records/preferences after confirmation and does not remove an Amazon purchase. The UI and localized store captures use real screens with fictional test records. No cloud sync, advertising or remote AI service is included.
