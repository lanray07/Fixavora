# Fixavora release instructions

The release candidate is 1.0.0 (version code 2), package `com.fixavora.app`. Check `RELEASE_READINESS.md` and artifact hashes for the current validated revision before uploading. A request to prepare the release does not authorize the final Amazon submission.

1. Run the README validation commands against the final revision. Keep localization and full lint checks active. Regenerate the Android test fixtures before screenshot tests. Verify GitHub CI for the same source revision.
2. Run the device workflows on a disposable debug installation. `tools/sandbox_qa.py --serial SERIAL --documents --workflows` installs only Fixavora APKs and preserves the existing Amazon App Tester SKU file and SDK mode. These fixtures replace Fixavora's own debug records. No live checkout is clicked.
3. Verify the real localized tablet and compact captures, file counts, native script shaping and readable headings. Check the screenshot manifests. Only claim devices and speech capabilities actually tested. The connected KFTRWI has no Android recognition engine; typing works and three English TTS variants synthesize.
4. Run `python tools/package_delivery.py` to copy versioned APKs and produce hashes/inventory. Verify that release contains the production Worker URL and public Amazon authentication key, excludes test hosts/fixtures, and contains no shared secret or publisher private signing key.
5. Confirm the production Worker `/health` is configured for production. The encrypted Amazon shared secret remains server-side. Keep Workers Free; do not enable billing automatically. The free cap is an availability limit. Development sandbox and production endpoints must remain separate.
6. In Amazon, replace the old binary with the version-2 unsigned release APK, review parsed manifest/device compatibility, and retain only the intended Fire tablet targets. The current minimum API excludes older Fire OS versions; TV and automotive targets are outside this release.
7. Verify support `banksmi@mail.com`, publisher O. Bankole, GitHub support/privacy URLs, category Productivity / To-Do Lists & Reminders, all saved description locales and every supported image-localization slot. Amazon offers 15 description locales and 11 image locales in this account; other generated assets are delivered locally.
8. Review privacy answers against the implemented local storage, optional OS speech/document services and receipt-only Cloudflare/Amazon processing. Do not claim blanket legal compliance. The export certification was explicitly authorized by the publisher; do not change or accept new legal declarations without appropriate authorization.
9. Confirm the entitlement draft `fixavora.premium.lifetime` has its actual one-time price, title, description and icons. Amazon App Tester verification is genuine sandbox evidence. Production charging and Amazon-signed/LAT distribution are separate, untested paths. LAT is an optional additional prelaunch check, not an App Tester result.
10. Leave the app and IAP drafts unsubmitted until the publisher authorizes the actual submissions. When authorized, submit the IAP and app through Amazon's prescribed flow and retain the resulting review status. Store approval is an external result and must never be inferred from a complete draft.

For distribution outside Amazon, obtain a publisher-controlled signing key and verify the signed APK separately. The unsigned upload artifact cannot be installed directly. Core local records remain available without Premium; no production unlock or fake purchase is included.
